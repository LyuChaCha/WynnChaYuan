## `npc-collisions-before.txt` / `npc-collisions-after.txt`

`npc.json` 的「一個譯名對兩個不同原文」報表，判準是**跨語言投票**：

* 四個以上語言分得開 → 這是兩個不同的東西，撞在一起的語言要修
* 四個以上語言撞在一起 → 這是同一個東西，不要動

`before` 是 2026-10-05 修之前的 79 對（`[5/6]` 44 ＋ `[4/6]` 10 ＝ 54 對要修、
`[3/6]`+`[2/6]` 17 對待判、`[1/6]`+`[0/6]` 8 對是同一個東西）。
`after` 是修完剩下的 26 對——那 26 對就是**不該被報成錯**的對照組，裡面包含
刻意留著的 `Corrupted Slinger`／`Corruption Slinger`（zh_tw 兩邊都是「腐敗投石手」，
因為 zh_tw 的 Corrupt 整族都譯「腐敗」，要改是整族一起改）。

六行並排是這份報表唯一真正好用的地方：一眼就看得出「其他語言分得開，所以這是
兩個東西」還是「大家都一樣，所以本來就是同一個」。
