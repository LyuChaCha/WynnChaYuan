# B站影片下載器（Chrome 擴充功能）

在 bilibili 影片頁右下角加上粉紅色「⬇ 下載」按鈕，可選擇畫質下載。

## 安裝

1. 打開 `chrome://extensions`
2. 右上角開啟「開發人員模式」
3. 按「載入未封裝項目」，選擇這個 `bilibili-downloader` 資料夾
4. 打開任一 `https://www.bilibili.com/video/BV...` 頁面，右下角就會出現下載按鈕

## 功能

- **完整 MP4**：影像與聲音合在一起，下載後可直接播放（畫質通常最高 720P／1080P）。
- **高畫質（DASH）**：影像與音訊分開提供，可選 1080P 60 幀、4K、HDR 等，以及 H.264／H.265／AV1 編碼。
  下載後用 ffmpeg 合併（只是重新封裝，不會重新編碼）：
  ```
  ffmpeg -i "xxx.video.mp4" -i "xxx.audio.m4a" -c copy "xxx.mp4"
  ```
  相容性最好的是 **H.264**；H.265／AV1 檔案較小，但部分播放器不支援。
- 支援多分P影片（自動選中目前網址的 `?p=`）。
- 下載時按鈕會顯示進度百分比，檔案存到瀏覽器預設的下載資料夾。

## 說明

- 使用你在 bilibili 的登入狀態取得播放地址，所以能下載的畫質和你帳號能看的一樣。
  未登入通常只有 480P／720P；1080P 高碼率、4K 等需要大會員。本擴充**不會**繞過付費或會員限制。
- 檔案會先下載到記憶體再存檔，很長的 4K 影片會佔用較多記憶體。
- 目前只支援一般影片頁（`/video/`），番劇、課程、直播尚未支援。
- 下載的內容請僅供個人使用，並尊重 UP 主的著作權。

## 檔案結構

| 檔案 | 用途 |
| --- | --- |
| `manifest.json` | 擴充功能設定（Manifest V3） |
| `api.js` | 呼叫 B站 API（影片資訊、播放地址、WBI 簽名） |
| `md5.js` | WBI 簽名用的 MD5 |
| `content.js` | 頁面上的下載按鈕與面板 |
| `popup.html` / `popup.js` | 點工具列圖示時的小視窗 |
