# Wynncraft 故事導讀

> 這一套文件會**劇透**幾乎所有任務、隱藏探索點與祕密故事。每一章開頭另有該章的劇透提醒。

這是給玩家與譯者看的繁體中文故事導讀：把 Wynncraft 的主線、支線任務、隱藏探索點與祕密內容整理成讀得懂的敘事，說明「發生了什麼、誰是誰、哪裡埋了伏筆」。台詞照本專案語料裡的繁中譯文引用；伏筆、雙關與暗示會另外點出來，而不是逐句直譯。

要找**譯名怎麼翻**，看 [GLOSSARY.md](../../GLOSSARY.md)；要先抓整個世界的骨架，可以先讀團隊的 [世界觀與主線](../world-and-story.md)。

## 寫法與標記

- **事實與推測分開**：遊戲或 wiki 明說的照寫；作者的推論標「（推測）」，社群說法標「（社群說法）」。
- **出處**：每節末尾標「出處：任務《…》／wiki〈頁名〉」。wiki 指 [Wynncraft Wiki（wiki.gg）](https://wynncraft.wiki.gg/)，內容是改寫與摘要，不是轉載；原頁面的授權照 wiki 的規定。
- **譯名**：任務名、怪物、道具與術語照語料與 GLOSSARY；人名、地名、地區名照慣例留英文。語料裡還沒有的詞，各章文末「本章新出現的譯名」有原文對照，**還沒定案**，正式進語料前要先討論。跨章共用的詞見下方「全書統一用詞」。
- **語料沒收的台詞**：探索點過場、石板文字等語料沒有的句子，文中標「本章自譯」或「本章轉述」。
- **年代**：以 wiki〈[Timeline](https://wynncraft.wiki.gg/wiki/Timeline)〉（2.2.3 版）為主；其他頁面或舊版的說法另加註記。

## 第二輪修訂（2026-10-22）

第一輪撰寫時 wiki.gg 全站下線，許多頁面讀不到。第二輪補讀了這些頁面，並做了跨章一致性檢查：

- 補進的內容：Creden Tibus 與皇帝之杖（第一章）、《死亡之哨》的草藥學之書與 Gale Nasin、《光之領域》咒文的譯解（第二章）、峽谷巨像討伐戰與巨像身世、Sohso 的下落（第三章）、Gateway Island 與門後的山谷、Grook 學院的牢房筆記、Doguns、Ahms 巨像、天空劫掠者的衰落（第四章）、Dern 在各地的痕跡、影響領域（第五章）、Hallowground 計畫的六份文件（第六章）。
- 更正的年代：「影響領域與物質界失聯」不是 4000 BP（第五章）；四顆水晶出土以 300 AP 為準（第五章）；沙漠皇帝之死是 688 BP（第七章）；Gale 是在畢業前夕出逃（第六章）。
- 有幾個第一輪列為「讀不到」的頁面，其實在 wiki.gg 上**不存在**：Emperor's_Sceptre、Realm_of_Light_(Quest_Line)、Markus_Corkus、Skyraiders、Ahms_Colossus、Realms_of_Influence、Fruma_Storyline、Project_Hallowground。各章已改從相關頁面取材，並在出處清單註明。
