# Wynncraft 故事導讀

> 這一套文件會**劇透**幾乎所有任務、隱藏探索點與祕密故事。每一章開頭另有該章的劇透提醒。

這是給玩家與譯者看的繁體中文故事導讀：把 Wynncraft 的主線、支線任務、隱藏探索點與祕密內容整理成讀得懂的敘事，說明「發生了什麼、誰是誰、哪裡埋了伏筆」。台詞照本專案語料裡的繁中譯文引用；伏筆、雙關與暗示會另外點出來，而不是逐句直譯。

要找**譯名怎麼翻**，看 [GLOSSARY.md](../../GLOSSARY.md)；要先抓整個世界的骨架，可以先讀團隊的 [世界觀與主線](../world-and-story.md)。

## 寫法與標記

- **事實與推測分開**：遊戲或 wiki 明說的照寫；作者的推論標「（推測）」，社群說法標「（社群說法）」。
- **出處**：每節末尾標「出處：任務《…》／wiki〈頁名〉」。wiki 指 [Wynncraft Wiki（wiki.gg）](https://wynncraft.wiki.gg/)，內容是改寫與摘要，不是轉載；原頁面的授權照 wiki 的規定。
- **譯名**：任務名、怪物、道具與術語照語料與 GLOSSARY；人名、地名、地區名照慣例留英文。語料裡還沒有的詞，各章文末「本章新出現的譯名」有原文對照，**還沒定案**，正式進語料前要先討論。
- **語料沒收的台詞**：探索點過場、石板文字等語料沒有的句子，文中標「本章自譯」或「本章轉述」。

## 怎麼更新

劇情隨遊戲改版會變。發現跟實機不符的地方，直接改對應章節並註明版本；新增任務照該章的結構補一節（劇情、人物、伏筆、出處）。
