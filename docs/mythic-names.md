# Mythic 譯名對照

這份是給翻譯團隊審的。**取名不走直譯**——每個名字都是從那件裝備自己的 lore
長出來的，不是從英文字面。

`Alkatraz` 直譯是「惡魔島」，但那個典故在 Wynncraft 裡並不存在；它的 lore 寫的是一把
外表平凡、裡面封著鎖魂咒的巨槌，所以叫「鎖魂囚槌」。

`Masterwork` 系列是同一把武器的高階重製版，統一冠上「匠鑄・」，
名字本體沿用原本那一把，玩家一眼就看得出是同一件東西。

專有名詞（Gavel、Theorick、Garaheth…）一律留原文，跟既有的十四條譯文一致。
武器類型跟著對照表：relik 法器、wand 魔杖、spear 矛、dagger 匕首、bow 弓。

名稱吃 F6 的「翻譯物品名稱」開關——想對得上交易市場與 wiki 的人可以關掉，
關掉之後只有背景敘述會翻。

覺得哪個名字不對，直接改這裡的「譯名」欄，我再同步進譯文檔。
