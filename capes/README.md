# 披風

名單上的玩家可以有一件 WynnChaYuan 披風，其他裝了模組的人都看得到。

## 怎麼加一件

1. 把圖檔放進這個資料夾。檔名只能用小寫英數、`-`、`_`，副檔名是 `.png` 或 `.gif`，例如 `leaf.gif`。
2. 在 `src/main/resources/assets/wynnchayuan/credits.json` 那個人的條目加一欄 `"cape": "leaf.gif"`。

合併之後，玩家下次同步名單就會看到（圖檔在本機快取一天）。

## 圖怎麼畫

**只畫背後看到的那一面就好。** 任何尺寸都收，比例 10:16（例如 40×64、100×160）最剛好；比例不對的會置中裁掉多的部分。內側、四邊由模組自己補。

- PNG：靜態的披風。
- GIF：會動的披風，直接丟一個 GIF，不必拆成一格一格。每一格停多久照 GIF 裡寫的。

另外兩種也收，已經做好的檔不必重做：

- Minecraft 的完整披風版型（寬是高的兩倍、寬是 64 的倍數，例如 64×32、128×64）。
- Wynntils 那種直排多格的 PNG（每一格是一張完整版型，從上往下排）。

版型右邊鞘翅那一塊用不到，留空就好。

## 上限

- 檔案 4 MB 以內。
- GIF 畫布一邊 1024 像素以內，最多 120 格（超過的不播）。
- 格數越多，每一格在遊戲裡的解析度越低——整件披風有固定的記憶體預算。一般 20 格以內、一面 80×128 以內看不出差別。
- 透明的地方會變成黑色（披風是不透明的）。

## 先在自己身上看效果

把圖放進遊戲資料夾的 `config/wynnchayuan/capes/`，命名為 `self.png` 或 `self.gif`（F6 →「娛樂」→「打開資料夾」）。只有自己看得到，存檔之後幾秒內就換上，適合邊改邊看。
