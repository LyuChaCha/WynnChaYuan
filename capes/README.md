# 披風

WynnChaYuan 的披風，裝了模組的人都看得到。有兩條路：

- **自己上傳**：在 [wynnchayuan.com/capes](https://wynnchayuan.com/capes) 上傳（遊戲裡 F6 →「功能」→「披風一覽」會順便替你登入）。網站上就看得到穿在身上的樣子。
- **登記在名單上**：把圖檔放進這個資料夾，在 `credits.json` 那個人的條目加一欄 `"cape": "檔名.gif"`。

兩個都有的人，用上傳的那一件。

## 範本

披風要照 `templates/` 裡的範本畫：正面、背面、邊框都在同一張圖上，沒有多餘的空白。

![範本說明](templates/guide.png)

| 範本 | 尺寸 | 示範 |
|---|---|---|
| `templates/template-22x17.png` | 22×17 | `example-22x17.gif` |
| `templates/template-44x34.png` | 44×34 | `example-44x34.gif` |
| `templates/template-88x68.png` | 88×68 | `example-88x68.gif`、`example-88x68.png` |
| `templates/template-176x136.png` | 176×136 | `example-176x136.gif` |
| `templates/template-352x272.png` | 352×272 | — |
| `templates/template-704x544.png` | 704×544 | — |
| `templates/template-1056x816.png` | 1056×816 | — |

遊戲裡披風最多用到 352×272，更大的兩種在遊戲裡看起來一樣，主要是網站上比較清楚。

- **藍色＝正面**：別人從你背後看到的那一面（10×16 格）。
- **紅色＝背面**：貼著身體的那一面（10×16 格）。
- **青色＝邊框**：上緣、下緣、左右兩邊（1 格厚）。
- 左上、右上兩個角用不到。

四個尺寸是同一個版型放大 1、2、4、8 倍（一格是 1、2、4、8 個像素），越大越細緻。

這個版型就是 Minecraft 披風貼圖左上角用得到的那一塊，右邊鞘翅與下面的空白裁掉了。

### PNG 與 GIF

- PNG：靜態的披風。
- GIF：會動的披風。直接用一個 GIF，不必拆成一格一格；**每一格都照同一個版型畫**（每一格都有正面、背面、邊框）。每一格停多久照 GIF 裡寫的。

## 上傳的規則

- 尺寸要是上面四種之一。不照範本尺寸的圖不收。
- 檔案大小：一般玩家 1 MB 以內；開發者、贊助者、貢獻者 20 MB 以內。
- GIF 最多 120 格。
- 透明的地方會變成黑色（披風是不透明的）。
- 格數越多，每一格在遊戲裡的解析度越低——整件披風有固定的記憶體預算。20 格以內看不出差別。
- 檔案越大，別人第一次看到你的時候要下載越久。

誰可以上傳由登記站決定（`tools/presence` 的 `UPLOADS`）。預設：

- **PNG**：裝了模組、驗過身分的人都能傳。
- **GIF**：只有開發者、贊助者、貢獻者。

**不可以上傳的內容：政治、不雅或色情、違反法規、種族歧視或仇恨；廣告（商業宣傳、宣傳其他伺服器、真錢交易例如用現金買賣 LE、現實生活的聯絡方式——公會宣傳不算）；以及其他違反 Wynncraft 規章的內容。也不可以濫用上傳。** 違規的披風會被移除，上傳的人可能不能再傳。

- **冷卻**：一小時內上傳 3 次以上，要等 12 小時才能再傳。
- **在審核名單上的人**只能有一件自己傳的披風（等審核的也算）；要換一件，先移除現在這件。

所有上傳的披風可以在 [wynnchayuan.com/capes](https://wynnchayuan.com/capes) 看到（遊戲裡 F6 →「功能」→「披風一覽」會順便替你登入，登入之後也可以在網站上傳）。相同的圖只存一份。開發者登入之後可以刪除違規的披風、封禁上傳的人。

## 登記在名單上的圖

放在這個資料夾、由 `credits.json` 指到的圖是維護者自己放的，規則寬一點：除了範本的尺寸，也收 Minecraft 的完整披風版型（64×32 的倍數）、Wynntils 那種直排多格的 PNG、以及只畫正面的圖（任何尺寸，置中裁成 10:16，背面與邊框由模組補）。檔名只能用小寫英數、`-`、`_`，副檔名 `.png` 或 `.gif`。
