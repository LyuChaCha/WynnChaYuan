# 披風

WynnChaYuan 的披風，裝了模組的人都看得到。有兩條路：

- **自己上傳**：F6 →「徽章與披風」→「上傳披風」。上傳之前先在自己身上看過（見最下面）。
- **登記在名單上**：把圖檔放進這個資料夾，在 `credits.json` 那個人的條目加一欄 `"cape": "檔名.gif"`。

兩個都有的人，用上傳的那一件。

## 範例版型

`templates/` 裡有可以直接拿來畫的版型，`guide.png` 是說明圖。

![版型說明](templates/guide.png)

### 完整版型（正面、背面、邊框都自己畫）

| 檔案 | 尺寸 |
|---|---|
| `templates/full-64x32.png` | 64×32 |
| `templates/full-128x64.png` | 128×64 |
| `templates/full-256x128.png` | 256×128 |

- **藍色＝正面**：別人從你背後看到的那一面。
- **紅色＝背面**：貼著身體的那一面。
- **青色＝邊框**：上緣、下緣、左右兩邊。
- 其餘留空。右邊原本是鞘翅的位置，用不到。

示範：`templates/example-full-64x32.gif`、`example-full-128x64.gif`、`example-full-256x128.gif`。

### 只畫一面（背面與邊框由模組補）

| 檔案 | 尺寸 |
|---|---|
| `templates/face-20x32.png` | 20×32 |
| `templates/face-40x64.png` | 40×64 |
| `templates/face-80x128.png` | 80×128 |
| `templates/face-160x256.png` | 160×256 |

整張圖就是正面。背面是它左右反過來的暗色版，邊框取圖最外面那一圈的顏色。

示範：`templates/example-face-40x64.gif`、`example-face-80x128.gif`、`example-face-40x64.png`。

### PNG 與 GIF

- PNG：靜態的披風。
- GIF：會動的披風。直接用一個 GIF，不必拆成一格一格；**每一格都照同一個版型畫**（完整版型的 GIF，每一格都有正面、背面、邊框）。每一格停多久照 GIF 裡寫的。

## 上傳的規則

- 尺寸要是上面七種之一。
- 檔案 1 MB 以內。
- GIF 最多 60 格。
- 透明的地方會變成黑色（披風是不透明的）。
- 格數越多，每一格在遊戲裡的解析度越低——整件披風有固定的記憶體預算。20 格以內、一面 80×128 以內看不出差別。

誰可以上傳由登記站決定（`tools/presence` 的 `UPLOADS`）：預設是名單上的成員。

## 登記在名單上的圖

放在這個資料夾、由 `credits.json` 指到的圖，規則寬一點：任何尺寸都收（比例不是 10:16 也不是完整版型的，當成「只畫一面」置中裁掉多的），4 MB 以內、最多 120 格。Wynntils 那種直排多格的 PNG 也可以直接用。檔名只能用小寫英數、`-`、`_`，副檔名 `.png` 或 `.gif`。

## 先在自己身上看效果

把圖放進遊戲資料夾的 `config/wynnchayuan/capes/`，命名為 `self.png` 或 `self.gif`（F6 →「徽章與披風」→「打開資料夾」）。只有自己看得到，存檔之後幾秒內就換上，適合邊改邊看。看滿意了，同一頁按「上傳」，送出去的就是這個檔。
